# Acknowledgments & Attribution

## Research Foundations

### ACE (Autonomous Cognitive Entity) Framework

This project is inspired by the ACE framework:

> **ACE: A Toolkit for Self-Improving Autonomous Agents**
> arXiv:2510.04618 [cs.AI], October 2024
> https://arxiv.org/abs/2510.04618

**Our Adaptation**: While the original ACE paper focused on autonomous AI self-improvement through cognitive architecture, **ACE Enterprise pivots to institutional knowledge infrastructure**.

Rather than improving autonomous coding capability, we focus on:
- Capturing human+AI decision-making context (the WHY, not just the WHAT)
- Building organizational memory that persists beyond individual developers
- Creating cross-project learning through shared patterns
- Documenting rationale that helps teams understand past decisions

**Key Divergence**: Original ACE aimed to make AI smarter at coding. We aim to make organizations smarter at preserving knowledge.

## Methodological Influences

### Acceptance Test-Driven Development (ATDD)

Our Gherkin-driven TDD workflow was inspired by:

**Dave Farley** - Modern Software Engineering
- Video: [Modern Software Engineering](https://www.youtube.com/watch?v=NsOUKfzyZiU)
- Book: *Continuous Delivery* (Farley & Humble, 2010)

Dave's emphasis on automating acceptance criteria through tests directly influenced our approach of mapping Gherkin scenarios to unit tests.

### Test-Driven Development (TDD)

> Beck, K. (2002). *Test-Driven Development: By Example*. Addison-Wesley.

The RED-GREEN-REFACTOR cycle is fundamental to our autonomous development approach.

### Behavior-Driven Development (BDD)

> North, D. (2006). Introducing BDD. https://dannorth.net/introducing-bdd/

Dan North's work on BDD and the Gherkin specification format enabled our acceptance test-driven approach.

## AI Collaboration

### Claude Code (Anthropic)

Significant portions of this codebase were developed through human-AI collaboration using Claude Code (Anthropic's AI assistant).

**What Claude helped with:**
- Code implementation based on human-specified requirements
- Architecture design discussions and feedback
- Documentation generation and editing
- Test case generation

**Important Context:**
1. **Human-Directed**: All architectural decisions, requirements, and strategic direction came from human contributors
2. **Human-Reviewed**: Every line of AI-generated code was reviewed, tested, and often modified by humans
3. **Human-Owned**: According to Anthropic's terms of service, users own the output generated by Claude
4. **Human-Responsible**: We take full responsibility for code quality, correctness, and maintenance

**Our Philosophy**: We practice what we preach. ACE Enterprise is about capturing human+AI collaboration - this project itself demonstrates that methodology. AI augments human capability but doesn't replace human judgment.
